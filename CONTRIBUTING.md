# Contributing to yaaa

Thanks for helping.

## Issues: yes, please

Open an issue for a bug, an idea, or a question. For a bug, include the output of `yaaa doctor` (it shows your yaaa version, platform, and whether the API and your account are reachable) and the command you ran. Remove anything personal first. Never post your recovery key, tokens, or confirm links.

## Pull requests: not yet

We're not accepting pull requests yet, while we decide how contributions are licensed. A pull request from outside the yaaa-io organization is closed automatically, with a note pointing here. If you have a fix, open an issue describing it; we may make the change ourselves.

This repo is a mirror of yaaa's command-line tool, skills, and API contract. It's updated with each release, so changes made directly here would be overwritten.
